# ClubFoundry Windows Agent

[Русская версия](WINDOWS_AGENT.ru.md) | [Installation](INSTALLATION.md)

The Windows Agent is optional. Install it on managed Windows PCs, not on the
TrueNAS server. The core TrueNAS, ZFS, ZVOL, and iSCSI management functions of
ClubFoundry remain available without it.

## What it adds

Depending on the modules enabled for a PC, the Agent can provide:

- current PC and Agent availability plus Windows-side diagnostics;
- automated Windows iSCSI connection and drive-letter operations;
- remote commands and controlled reboot operations;
- Steam update monitoring and Steam Auto triggers;
- optional TcNo Steam account rotation when that feature is configured.

## Installing through ClubFoundry

1. Open the ClubFoundry interface running on TrueNAS.
2. In the left menu, select `Management > Windows Agents`.
3. Expand `Onboarding (boot tokens)`.
4. Select the PC role:
   - `Admin PC (master)` for a computer used to update master disks;
   - `Club PCs` for a player computer that uses master-disk clones.
5. Set the command lifetime. Optionally add a note identifying the intended
   computer.
6. Click `Generate boot token`, then `Copy install command`. The command is shown
   after the token is issued and already contains this ClubFoundry server's
   address, the compatible MSI download address, and a single-use credential
   for the first connection.
7. On the Windows PC, open Command Prompt as administrator, paste the copied
   command, and press Enter. The command downloads Windows Agent from the
   ClubFoundry server, starts the installer, and passes the connection settings.
8. After installation and the first successful connection, the PC appears
   under `Installed agents`. The boot token is consumed and the Agent receives
   a separate permanent credential for this server.
9. Generate a new boot token for the next computer and repeat the steps. If a
   token expires or is revoked before the PC connects, generate a new one.

During initial setup, `Setup & Import` also offers an accelerated workflow for
enrolling multiple PCs. `Windows Agents` is the permanent place for installing
new Agents and managing them afterward.

## Installing the GitHub Release MSI manually

A compiled MSI is attached to the matching GitHub Release. Download it only
when the in-application command cannot download the file automatically. Keep
the `SERVERURL` and `BOOTTOKEN` values generated by ClubFoundry:

```bat
msiexec /i "ClubFoundryAgent-VERSION.msi" SERVERURL="ws://SERVER:PORT/api/v1/agents/ws/agent" BOOTTOKEN=TOKEN
```

Use the exact generated URL. It may use `wss://` when ClubFoundry is behind a
TLS reverse proxy. A boot token is an enrollment secret: do not post it in an
issue, commit it to Git, reuse it on another PC, or include it in a screenshot.
If it expires, generate a new command in ClubFoundry.

### Windows publisher warning for Agent 0.1.46

The 0.1.46 MSI is not Authenticode-signed, so Windows can display
`Unknown publisher`. Before continuing, verify the downloaded file against the
`ClubFoundryAgent-0.1.46.msi` line in the release's `SHA256SUMS`. Do not bypass
a hash mismatch.

## Existing Agent and updates

If the Agent is already installed and linked to the correct ClubFoundry
instance, do not create a second installation. The service keeps its protected
configuration, and supported updates are delivered through the paired
ClubFoundry update path.

If the Agent is already installed but managed by another ClubFoundry server,
do not reinstall it. On the new server, open `Management > Windows Agents`,
expand `Bind this server to a PC that already has an agent`, and follow the
invitation workflow using the six-digit confirmation code. Do not copy tokens
or protected configuration files between PCs.
