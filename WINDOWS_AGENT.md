# Optional ClubFoundry Windows Agent

[Русская версия](WINDOWS_AGENT.ru.md) | [Installation](INSTALLATION.md)

The Windows Agent is optional. Install it on managed Windows PCs, not on the
TrueNAS server. The core TrueNAS, ZFS, ZVOL, and iSCSI management functions of
ClubFoundry remain available without it.

## What it adds

Depending on the modules enabled for a PC, the Agent can provide:

- current PC and Agent availability plus Windows-side diagnostics;
- automated Windows iSCSI connection and drive-letter operations;
- remote commands and controlled reboot operations;
- Steam update monitoring and Steam Auto triggers;
- optional TcNo Steam account rotation when that feature is configured.

## Recommended installation

1. Install and open the ClubFoundry server application first.
2. In ClubFoundry, add or select the Windows PC.
3. Open the Windows Agent installation section and generate its connection
   command. The command contains the correct WebSocket server URL and a
   short-lived boot token.
4. Run that generated command in an elevated Command Prompt on the intended
   Windows PC.

This is the preferred path because the MSI by itself cannot determine which
ClubFoundry instance and PC it should join.

## Installing the GitHub Release MSI manually

A compiled MSI is attached to the matching GitHub Release. Download it only
when the in-application command cannot download the file automatically. Keep
the `SERVERURL` and `BOOTTOKEN` values generated by ClubFoundry:

```bat
msiexec /i "ClubFoundryAgent-VERSION.msi" SERVERURL="ws://SERVER:PORT/ws/agent" BOOTTOKEN=TOKEN
```

Use the exact generated URL. It may use `wss://` when ClubFoundry is behind a
TLS reverse proxy. A boot token is an enrollment secret: do not post it in an
issue, commit it to Git, reuse it on another PC, or include it in a screenshot.
If it expires, generate a new command in ClubFoundry.

### Windows publisher warning for Agent 0.1.46

The 0.1.46 MSI is not Authenticode-signed, so Windows can display
`Unknown publisher`. Before continuing, verify the downloaded file against the
`ClubFoundryAgent-0.1.46.msi` line in the release's `SHA256SUMS`. Do not bypass
a hash mismatch.

## Existing Agent and updates

If the Agent is already installed and linked to the correct ClubFoundry
instance, do not create a second installation. The service keeps its protected
configuration, and supported updates are delivered through the paired
ClubFoundry update path.

For a PC linked to another instance, generate a command for the intended
instance and follow the reassignment flow shown by ClubFoundry. Do not copy
tokens or protected configuration files between PCs.
