# Необязательный Windows Agent ClubFoundry

[English version](WINDOWS_AGENT.md) | [Установка ClubFoundry](INSTALLATION.ru.md)

Windows Agent является необязательным компонентом. Он устанавливается на
управляемые компьютеры с Windows, а не на сервер TrueNAS. Основные функции
ClubFoundry для работы с TrueNAS, ZFS, ZVOL и iSCSI доступны без него.

## Какие функции он добавляет

В зависимости от включённых для ПК модулей Agent может обеспечивать:

- отображение доступности ПК и Agent, а также диагностику со стороны Windows;
- автоматическое подключение iSCSI в Windows и назначение букв дисков;
- удалённые команды и управляемую перезагрузку;
- наблюдение за обновлениями Steam и запуск сценариев Steam Auto;
- необязательную ротацию аккаунтов Steam через TcNo, если эта функция настроена.

## Рекомендуемая установка

1. Сначала установите и откройте серверное приложение ClubFoundry.
2. Добавьте или выберите в ClubFoundry нужный компьютер с Windows.
3. Откройте раздел установки Windows Agent и сформируйте команду подключения.
   В ней будут правильный WebSocket-адрес сервера и короткоживущий загрузочный
   токен.
4. Выполните сформированную команду в командной строке с правами администратора
   именно на том компьютере Windows, который нужно подключить.

Это основной способ установки: сам MSI не может определить, к какому инстансу
ClubFoundry и какому ПК его нужно привязать.

## Ручная установка MSI из GitHub Release

Собранный MSI приложен к соответствующему GitHub Release. Скачивайте его
вручную только если команда из приложения не смогла получить файл
автоматически. Сохраните значения `SERVERURL` и `BOOTTOKEN`, сформированные
ClubFoundry:

```bat
msiexec /i "ClubFoundryAgent-VERSION.msi" SERVERURL="ws://SERVER:PORT/ws/agent" BOOTTOKEN=TOKEN
```

Используйте адрес точно из сформированной команды. При работе через обратный
прокси с TLS он может начинаться с `wss://`. Загрузочный токен является секретом
регистрации. Не публикуйте его в Issues, не добавляйте в Git, не используйте на
другом ПК и не показывайте на снимках экрана. Если срок токена истёк,
сформируйте в ClubFoundry новую команду.

## Уже установленный Agent и обновления

Если Agent уже установлен и привязан к нужному инстансу ClubFoundry, второй
экземпляр устанавливать не нужно. Служба сохраняет защищённую конфигурацию, а
поддерживаемые обновления получает через связанный механизм ClubFoundry.

Если ПК привязан к другому инстансу, сформируйте команду для нужного инстанса и
используйте показанный ClubFoundry сценарий перепривязки. Не копируйте токены и
защищённые файлы конфигурации между компьютерами.
