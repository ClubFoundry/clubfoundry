# Windows Agent ClubFoundry

[English version](WINDOWS_AGENT.md) | [Установка ClubFoundry](INSTALLATION.ru.md)

Windows Agent является необязательным компонентом. Он устанавливается на
управляемые компьютеры с Windows, а не на сервер TrueNAS. Основные функции
ClubFoundry для работы с TrueNAS, ZFS, ZVOL и iSCSI доступны без него.

## Какие функции он добавляет

В зависимости от включённых для ПК модулей Agent может обеспечивать:

- отображение доступности ПК и Agent, а также диагностику со стороны Windows;
- автоматическое подключение iSCSI в Windows и назначение букв дисков;
- удалённые команды и управляемую перезагрузку;
- наблюдение за обновлениями Steam и запуск сценариев Steam Auto;
- необязательную ротацию аккаунтов Steam через TcNo, если эта функция настроена.

## Установка через ClubFoundry

1. Откройте интерфейс ClubFoundry, установленного на TrueNAS.
2. В левом меню выберите `Управление > Windows-агенты`.
3. Разверните блок `Подключение (boot-токены)`.
4. Выберите роль компьютера:
   - `Админ-ПК (мастер)` — компьютер, на котором обновляется содержимое
     мастер-дисков;
   - `Клубные ПК` — обычный игровой компьютер, использующий клоны
     мастер-дисков.
5. Укажите срок действия команды. При необходимости добавьте заметку, чтобы
   было понятно, для какого компьютера она создана.
6. Нажмите `Выпустить boot-токен`, затем `Скопировать команду установки`.
   Команда показывается после выпуска токена и уже содержит адрес этого сервера
   ClubFoundry, адрес загрузки совместимого MSI и разовый токен первого
   подключения.
7. На подключаемом компьютере откройте `Командную строку` от имени
   администратора, вставьте скопированную команду и нажмите Enter. Команда сама
   скачает Windows Agent с сервера ClubFoundry, запустит установщик и передаст
   ему настройки подключения.
8. После установки и первого успешного подключения компьютер появится в блоке
   `Установленные агенты`. Boot-токен будет использован, а Agent получит
   отдельный постоянный ключ этого сервера.
9. Для следующего компьютера выпустите новый boot-токен и повторите действия.
   Если токен истёк или был отозван до подключения, создайте новый.

Во время первичной настройки раздел `Настройка и импорт` также предлагает
ускоренный сценарий подключения сразу нескольких ПК. Постоянным местом для
установки новых Agent и дальнейшего управления ими является раздел
`Windows-агенты`.

## Ручная установка MSI из GitHub Release

Собранный MSI приложен к соответствующему GitHub Release. Скачивайте его
вручную только если команда из приложения не смогла получить файл
автоматически. Сохраните значения `SERVERURL` и `BOOTTOKEN`, сформированные
ClubFoundry:

```bat
msiexec /i "ClubFoundryAgent-VERSION.msi" SERVERURL="ws://SERVER:PORT/api/v1/agents/ws/agent" BOOTTOKEN=TOKEN
```

Используйте адрес точно из сформированной команды. При работе через обратный
прокси с TLS он может начинаться с `wss://`. Загрузочный токен является секретом
регистрации. Не публикуйте его в Issues, не добавляйте в Git, не используйте на
другом ПК и не показывайте на снимках экрана. Если срок токена истёк,
сформируйте в ClubFoundry новую команду.

### Предупреждение Windows для Agent 0.1.46

MSI версии 0.1.46 не подписан Authenticode, поэтому Windows может показать
`Неизвестный издатель`. Перед продолжением сравните скачанный файл со строкой
`ClubFoundryAgent-0.1.46.msi` в файле `SHA256SUMS` этого выпуска. При
несовпадении SHA-256 установку продолжать нельзя.

## Уже установленный Agent и обновления

Если Agent уже установлен и привязан к нужному инстансу ClubFoundry, второй
экземпляр устанавливать не нужно. Служба сохраняет защищённую конфигурацию, а
поддерживаемые обновления получает через связанный механизм ClubFoundry.

Если Agent уже установлен, но управляется другим сервером ClubFoundry,
переустанавливать его не нужно. На новом сервере откройте
`Управление > Windows-агенты`, разверните блок
`Привязать этот сервер к ПК с уже установленным агентом` и выполните показанный
сценарий приглашения с шестизначным кодом подтверждения. Не копируйте токены и
защищённые файлы конфигурации между компьютерами.
