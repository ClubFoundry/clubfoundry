# ClubFoundry

[English version](README.md)

ClubFoundry автоматизирует обновление и распределение игровых библиотек
компьютерного клуба, размещённых на TrueNAS. Windows загружается с локального
системного диска каждого ПК, а игровые библиотеки находятся на отдельном сетевом
ZVOL-клоне мастер-диска для каждого компьютера и подключаются штатным инициатором
Windows по iSCSI. Это гибридная схема, называемая `half-diskless`.

Благодаря этому не требуется хранить полную игровую библиотеку на локальном SSD
каждого компьютера, что позволяет значительно уменьшить необходимый объём этих
SSD.

ZFS-клоны при этом не дублируют мастер-диск целиком: неизменённые блоки данных
остаются общими, а дополнительное место на сервере занимают только данные,
которые различаются между мастер-диском, сохранёнными версиями и отдельными
клонами. Поэтому 30 клонов библиотеки объёмом 10 ТБ сами по себе не требуют
300 ТБ физического пространства: базовый расчёт составляет 10 ТБ для исходной
библиотеки плюс 10-200 ГБ запаса под изменения на каждый ПК клуба. Сохранение
дополнительных версий и больший объём индивидуальных изменений увеличивают
фактический расход места.

В ClubFoundry можно вести несколько исходных игровых ZVOL, то есть мастер-дисков
с играми (`source/master disk`, `golden disk`, `source ZVOL`). Для каждого ПК
программа создаёт отдельный записываемый клон выбранного мастер-диска и управляет
его назначением этому компьютеру.

После обновления игр на мастер-диске ClubFoundry создаёт новую версию и позволяет
централизованно перевести на неё выбранные компьютеры или весь клуб, то есть
«раскатать обновление». Каждый ПК работает со своим клоном, поэтому внесённые на
нём изменения не затрагивают мастер-диск и остальные компьютеры.

## Установка

В GitHub Release опубликован готовый офлайн-комплект с собранными образами
ClubFoundry и обновлятора. Его можно установить на TrueNAS SCALE или другой
Linux-сервер с Docker. В репозитории также доступен сетевой установщик.

Требования, команды, выбор режима использования, обновление и предупреждения
об удалении описаны в [инструкции по установке](INSTALLATION.ru.md).

## Необязательный Windows Agent

Windows Agent не нужен для основной работы с TrueNAS, ZFS, ZVOL и iSCSI.
Устанавливайте его только на компьютеры с Windows, где нужны автоматизация на
стороне ПК, отображение текущего состояния, удалённые команды или автоматизация
Steam.

См. [инструкцию по Windows Agent](WINDOWS_AGENT.ru.md). MSI нельзя устанавливать
на TrueNAS.

## Что опубликовано в репозитории

Публичный репозиторий намеренно содержит только:

- исходный код установщика;
- исходный код контейнера-обновлятора;
- конфигурацию развёртывания и пользовательскую документацию;
- собранные образы приложения и собранный Windows Agent во вложениях GitHub
  Release, а не в истории Git.

Исходный код основного приложения ClubFoundry и Windows Agent является закрытым
и здесь не публикуется. Точная граница описана в разделе
[«Лицензирование»](LICENSE.md).

## Режимы использования

Режим выбирается отдельно для каждого инстанса:

- Личное некоммерческое использование бесплатно для 30 управляемых ПК, не
  считая администраторские компьютеры.
- Коммерческое или профессиональное использование включает первые 10
  управляемых неадминистраторских ПК бесплатно и до 5 ZVOL на каждый такой ПК.
  Дополнительные ПК и платные модули тарифицируются по действующим условиям,
  отображаемым в приложении.

К одному аккаунту можно привязать одновременно коммерческие и некоммерческие
инстансы. Актуальные условия: <https://clubfoundry.net/eula> и
<https://clubfoundry.net/pricing>.
