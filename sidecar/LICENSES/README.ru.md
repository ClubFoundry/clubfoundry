# Тексты лицензий контейнера-обновлятора

[English version](README.md)

В этой папке находятся стандартные тексты лицензий, на которые ссылаются точные
списки `../runtime-packages.lock` и `../runtime-tools.lock`, а также лицензия
BSD-3-Clause для стандартной библиотеки Go, включённой в бинарный файл
обновлятора.

Тексты SPDX скопированы из SPDX License List 3.28.0. Их закреплённые URL
источников и значения SHA-256 записаны в `license-texts.lock` и проверяются
скриптом `../verify-release-evidence.py`.

`Public-Domain.txt` объясняет, почему у базы часовых поясов IANA нет обычного
текста лицензии. Уведомления для конкретных пакетов и адреса их исходного кода
остаются в `../THIRD_PARTY_NOTICES.md`.
