# Sidecar license texts

[Русская версия](README.ru.md)

This directory contains the standard license texts referenced by the exact
runtime inventories in `../runtime-packages.lock` and `../runtime-tools.lock`,
plus BSD-3-Clause for the Go standard library linked into the updater binary.

The SPDX texts are copied from the SPDX License List 3.28.0. Their pinned
source URLs and SHA-256 values are recorded in `license-texts.lock` and checked
by `../verify-release-evidence.py`.

`Public-Domain.txt` records why the IANA time-zone data has no conventional
license text. Package-specific attribution and source locations remain in
`../THIRD_PARTY_NOTICES.md`.
