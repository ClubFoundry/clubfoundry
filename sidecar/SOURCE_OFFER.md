# Corresponding Source Offer

For every ClubFoundry updater image distributed with object code covered by the
GNU General Public License version 2, ClubFoundry offers any third party the
complete corresponding source for the exact covered components in that image.
The offer includes the scripts used to control compilation and installation of
those components when the applicable license requires them.

This offer is valid for at least three years after ClubFoundry's last
distribution of the applicable updater image. Source will be provided through
a network download or, on request, a machine-readable physical medium for no
more than the reasonable cost of providing it.

Request the source at `support@clubfoundry.net`. Include the complete image
reference and immutable `sha256:` manifest digest from the release evidence so
the exact source set can be identified.

This offer applies only to third-party components whose licenses require
corresponding source. It does not change the license of the ClubFoundry-authored
updater source, which is provided under the MIT License.
