# Установка ClubFoundry

[English version](INSTALLATION.md) | [Описание проекта](README.ru.md)

Самый простой способ установки на TrueNAS SCALE:

1. Откройте веб-интерфейс TrueNAS.
2. Перейдите в `System > Shell`.
3. Вставьте команду ниже и нажмите Enter.

```bash
curl -fsSL https://raw.githubusercontent.com/ClubFoundry/clubfoundry/main/installer/install.sh | sudo bash
```

Если нужна пошаговая подготовка TrueNAS и пояснения к каждому действию,
используйте [простую инструкцию на сайте](https://clubfoundry.net/install).
Опытные администраторы могут выполнить ту же команду через SSH.

Остальная часть этого документа описывает требования и варианты ручной
установки из файлов GitHub.

## Требования

- TrueNAS SCALE 24.10 или новее с включённой службой Docker/Apps либо другой
  Linux-сервер с запущенным Docker;
- права `root` или доступ к `sudo`;
- постоянное хранилище. На сервере без TrueNAS явно укажите
  `--app-dir=/абсолютный/путь/clubfoundry`.

На поддерживаемой версии TrueNAS SCALE отдельно устанавливать дополнительные
утилиты не требуется: всё необходимое для обычной установки через
`System > Shell` уже есть в системе.

Только для установки на другом Linux-сервере убедитесь, что доступны `bash`,
`curl`, `jq` и `sha256sum`. Для ручной распаковки офлайн-комплекта GitHub Release
дополнительно требуется `tar`.

Сервер с ClubFoundry должен иметь доступ к API управления TrueNAS и к сети
iSCSI, которой будет управлять.

## Вариант 1: готовый комплект из GitHub Release

При этом варианте образы приложения не скачиваются с другого сервиса.

1. Откройте [GitHub Releases](https://github.com/ClubFoundry/clubfoundry/releases).
2. Выберите нужный выпуск. Выпуски с отметкой **Pre-release** являются
   альфа-версиями, это нужно учитывать при выборе.
3. Скачайте `clubfoundry-VERSION-offline.tar.gz` и `SHA256SUMS`.
4. Проверьте внешний архив по соответствующей строке в `SHA256SUMS`.
5. Скопируйте архив на сервер, распакуйте и запустите находящийся внутри
   установщик.

```bash
sha256sum -c SHA256SUMS --ignore-missing
tar -xzf clubfoundry-VERSION-offline.tar.gz
cd clubfoundry-VERSION-offline
sudo bash install.sh --offline="$PWD"
```

Перед `docker load` установщик сверяет собственные `MANIFEST`, скрипт установки
и оба архива образов с внутренним файлом `SHA256SUMS`.

На Linux-сервере без TrueNAS явно выберите постоянную папку:

```bash
sudo bash install.sh --offline="$PWD" \
  --app-dir=/srv/clubfoundry
```

## Вариант 2: сетевой установщик из GitHub

Сам скрипт загружается из GitHub, а собранные образы получает через проверяемый
сервис выпусков ClubFoundry и его зеркала.

```bash
curl -fL \
  https://raw.githubusercontent.com/ClubFoundry/clubfoundry/main/installer/install.sh \
  -o install.sh
less install.sh
sudo bash install.sh
```

Для автоматической установки явно задайте режим конкретного инстанса:

```bash
sudo bash install.sh --usage-mode=noncommercial
# или
sudo bash install.sh --usage-mode=commercial
```

При новой интерактивной установке скрипт сам задаёт этот вопрос. Существующий
инстанс сохраняет выбранный режим. Если у старой установки режим ещё не был
сохранён, обновлённое приложение один раз определит его и запишет результат.

## Постоянные данные на TrueNAS

В первую очередь установщик выбирает пул, уже назначенный службе TrueNAS Apps.
Если такого пула нет, но подключён ровно один подходящий ZFS-пул с данными,
используется он. При наличии нескольких пулов выбор нужно указать явно:

```bash
sudo bash install.sh --app-dir=/mnt/POOL/clubfoundry
```

Не размещайте постоянные данные ClubFoundry в `/opt`, `/var/lib`, загрузочном
пуле TrueNAS и других путях, принадлежащих непостоянному загрузочному окружению.

## Первый запуск

После установки скрипт выводит адрес веб-интерфейса, обычно
`http://IP-СЕРВЕРА:3000`. Откройте его в браузере, примите действующее
лицензионное соглашение и в мастере настройки укажите адрес TrueNAS и ключ API.
Ключ API не передаётся как открытый аргумент командной строки и не должен
попадать в Git.

## Обновление

Обычная установка через Compose включает отдельный контейнер-обновлятор.
Запускайте обновление со страницы обновлений ClubFoundry. Для ручного сетевого
обновления доступна команда:

```bash
sudo bash install.sh --update
```

Для офлайн-обновления скопируйте и распакуйте новый комплект, затем выполните:

```bash
sudo bash NEW-BUNDLE/install.sh --update --offline=/абсолютный/путь/к/NEW-BUNDLE
```

## Пробный запуск и удаление данных

`--dry-run` выводит рассчитанный план, не меняя файлы, образы и контейнеры:

```bash
sudo bash install.sh --dry-run --app-dir=/mnt/POOL/clubfoundry
```

`--clean-install` удаляет существующую базу данных и состояние ClubFoundry.
Это не обычная переустановка и не обновление. Используйте параметр только если
эти данные больше не нужны и имеется подходящая резервная копия.

## Windows Agent

Если требуется только серверное управление TrueNAS, ZFS и iSCSI, на этом
установка закончена. Для необязательного компонента Windows есть отдельная
[инструкция по Windows Agent](WINDOWS_AGENT.ru.md).
